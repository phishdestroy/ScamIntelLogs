Подключение домена и настройка бота

Для пользователей, ранее работавших с любыми аналогичными решениями, интерфейс бота будет интуитивно понятен.

При разработке бота основной акцент был сделан на простоту использования при сохранении максимально широкого функционала.

Подробный обзор главной страницы с разбором каждой кнопки не представляется целесообразным, поэтому сразу перейдём к процессу привязки домена.

После запуска бота в первую очередь необходимо перейти в раздел 👤 Профиль и указать кошелёк для выплат.

Дрейнер реализован с автоматической сплит системой, после вывода Ваш процент автоматически переводится на установленный Вами кошелёк.

Далее следует перейти в раздел 🌐 Мои домены, нажать кнопку ➕ Добавить домен, выбрать способ подключения By DNS и ввести домен, предназначенный для подключения.

Домен можно приобрести, например, через сервис @one_reg_bot.

Дальнейшие шаги являются стандартными: после получения двух NS-записей необходимо вернуться к регистратору домена и установить их. Проверка NS-записей осуществляется ботом каждые 5 минут. В случае корректной настройки вы получите уведомление об успешном подключении домена.

После подтверждения NS-записей можно перейти к настройке лендинга. Для этого необходимо открыть подключённый домен, нажать кнопку 🎨 Установить дизайн и указать название требуемого дизайна из списка, опубликованного в канале.

Настройка AML конфигураций

После установки дизайна вы получаете полностью функционирующий лендинг. Далее необходимо перейти в раздел 🔐 TronAML → ⚙️ AML Конфигурация и задать минимальный лимит списания — минимальную сумму баланса, при достижении которой будет производиться списание средств с кошелька. В этом же разделе можно указать допустимый процент AML-риска, отображаемый в отчётах (актуально для AML-лендингов; при использовании других типов лендингов данный параметр можно не изменять).

Кроме того, в разделе 🔐 TronAML доступен подраздел управления контрактами, где каждый аппрув может быть снят в любой момент соответствующей кнопкой. Также предусмотрена возможность индивидуальной настройки минимальной суммы вывода для каждого аппрува.

Управление контрактами

Раздел «Управление контрактами» предназначен для полного контроля над каждым подписанным контрактом. После подтверждения подписи каждый аппрув автоматически отображается в виде отдельной вкладки внутри данного раздела.

В рамках управления контрактами пользователю доступен следующий функционал:

  • индивидуальная настройка минимального лимита вывода для каждого контракта;

  • просмотр актуального баланса кошелька непосредственно внутри бота, без необходимости использования сторонних сервисов;

  • вывод всего доступного баланса кошелька нажатием одной кнопки.

Дополнительно реализована автоматическая система мониторинга пополнений. Дрейнер отслеживает пополнение баланса каждого аппрува и обнаруживает новые поступления в течение 10–15 секунд после появления транзакции в блокчейне. При фиксации пополнения вы незамедлительно получаете уведомление в бот отстука @NCtronbot. В случае если лимит снятия стоит меньше суммы поступившей на кошелек - дрейнер автоматически спишет поступившую сумму.

Данный подход обеспечивает оперативное реагирование и полный контроль над всеми активными контрактами в режиме реального времени.

Функция ⛽️ Buy Gas

Данная функция предназначена для аренды энергии в сети TRON и позволяет существенно упростить процесс взаимодействия с контрактами. Обращаем внимание, что на текущий момент функция временно не поддерживает работу с биржевыми Web3-кошельками.

После активации и корректной настройки функции пользователю не требуется наличие TRON на балансе для подписания смарт-контракта — необходимая энергия будет предоставляться автоматически.

Порядок настройки

  1. Перейдите в Telegram-бот @BuyTronEnergy_bot.

  2. Нажмите кнопку Balance — в появившемся меню будет доступна кнопка API.

  3. В следующем сообщении бот предоставит вам API Key.

  4. Полученный API Key необходимо привязать в боте настроек проекта.

Перед активацией функции убедитесь, что баланс в @BuyTronEnergy_bot пополнен, так как без положительного баланса аренда энергии будет недоступна.

Настройки Modal (модального окна)

Раздел Modal предназначен для персонализации и глубокой кастомизации модального окна подключения кошельков. Данный инструмент позволяет адаптировать интерфейс под индивидуальные требования и повысить удобство взаимодействия пользователей.

В рамках данного раздела вы можете:

  • отключать неиспользуемые или ненужные кошельки из списка доступных к подключению;

  • самостоятельно настраивать порядок отображения кошельков в модальном окне;

  • редактировать текстовые сообщения на каждом этапе подключения пользователя с помощью встроенного текстового редактора;

  • выбирать цветовую схему модального окна — светлую или тёмную, в зависимости от предпочтений или используемого дизайна.

Все изменения применяются оперативно и не требуют дополнительных действий со стороны службы поддержки, что обеспечивает полный контроль над внешним видом и логикой работы модального окна.

После завершения настройки лендинга рекомендуется запустить бота уведомлений @NCtronbot. В него будут поступать все уведомления о коннектах, аппрувах и выводах.
