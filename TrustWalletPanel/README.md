## Overview

**TrustWalletPanel** (internally `tttadmin.com`) is a sophisticated, custom-built phishing operation impersonating Trust Wallet. Operating since **January 2025** across **9+ rotating domains** and **8+ IP addresses**, it uses a live chat system where Russian-speaking operators manually social-engineer victims into sending cryptocurrency deposits under the pretense of "asset replacement," "OFAC compliance," and "wallet unblocking."

Over **14 months of operation**, the panel has processed **1,900 victim sessions** with **679 active victims**. Minimum **$100K+** stolen based on victim statements in chat. The real total is impossible to fully calculate — scammers rotate wallets, use TRON (TRC-20 USDT) as primary channel, and many victims don't state exact amounts.

---

## Scam Method

1. Victim discovers phishing domain via **Telegram channels**, **romance scams** (pig-butchering), or **search results**
2. Phishing site perfectly mimics Trust Wallet multi-chain interface with functional swap/staking UI
3. Victim creates or imports wallet — **mnemonic seed phrase and password captured** by the backend
4. Wallet appears functional with real token balances, staking pools, and network data
5. When victim attempts a withdrawal, the transaction "fails" or is "blocked"
6. **Live chat support** activates — operator impersonates Trust Wallet Support
7. Operator claims assets are **frozen** due to OFAC sanctions, AML violations, or wrong network usage
8. Victim is told to deposit an equivalent amount for **"asset replacement from common pool"**
9. If victim pays, operator demands **additional deposits** (repeat extraction)
10. If victim refuses, operator threatens **"OFAC jurisdiction transfer"** with tight deadlines
11. Stolen funds are moved through **rotating ETH, TRON, and BTC addresses**
