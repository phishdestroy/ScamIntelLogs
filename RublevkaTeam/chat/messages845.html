Вот готовый код для автоматического общения в Telegram с использованием OpenAI API и библиотеки Telethon.

Что делает этот скрипт?

Авторизуется в Telegram от твоего аккаунта.

Отслеживает входящие сообщения в указанном чате.

Отправляет их в OpenAI API (GPT-4) и получает ответ.

Отправляет ответ обратно в Telegram.



---

Что нужно перед запуском?

1. Установить зависимости:

pip install telethon openai



2. Зарегистрировать API-ключ OpenAI:

Получи API-ключ здесь: https://platform.openai.com/signup



3. Создать файл config.py с твоими данными:

# config.py
API_ID = 12554761 # Твой API ID из my.telegram.org
API_HASH = "139565aacf459d6854e1a5cf43d46598" # Твой API Hash
CHAT_ID = -1001234567890 # ID чата, где бот будет отвечать
OPENAI_API_KEY = "sk-..." # Твой API-ключ OpenAI

Чтобы узнать CHAT_ID, можешь использовать бота @username_to_id_bot.




---

Основной код (bot.py)

from telethon import TelegramClient, events
import openai
import config

# Авторизация в Telegram
client = TelegramClient("session_name", config.API_ID, config.API_HASH)

# Настройка OpenAI API
openai.api_key = config.OPENAI_API_KEY

async def generate_response(text):
"""Отправляет текст в OpenAI API и получает ответ."""
try:
response = openai.ChatCompletion.create(
model="gpt-4",
messages=[{"role": "system", "content": "Ты живой человек, участвующий в чате."},
{"role": "user", "content": text}]
)
return response["choices"][0]["message"]["content"]
except Exception as e:
return f"Ошибка OpenAI: {e}"

@client.on(events.NewMessage(chats=config.CHAT_ID))
async def handler(event):
"""Обрабатывает входящие сообщения в указанном чате."""
if event.is_private: # Исключаем личные сообщения
return

user = await event.get_sender()
if user.bot: # Не отвечаем ботам
return

text = event.raw_text
print(f"[{user.username}] {text}") # Логируем сообщение

response = await generate_response(text) # Получаем ответ от OpenAI
await event.reply(response) # Отправляем ответ в чат

# Запуск клиента
print("Бот запущен!")
client.start()
client.run_until_disconnected()
