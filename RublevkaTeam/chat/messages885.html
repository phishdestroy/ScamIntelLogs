Если нужно, чтобы ChatGPT отвечал именно от вашего аккаунта, а не через бота, можно использовать библиотеку telethon (но это рискованно — Telegram может забанить аккаунт).

Инструкция:

Установите telethon:

bash
Copy
pip install telethon openai
Получите api_id и api_hash на my.telegram.org.

python
Copy
from telethon import TelegramClient, events
import openai

api_id = "ВАШ_API_ID"
api_hash = "ВАШ_API_HASH"
session_name = "session_name"

client = TelegramClient(session_name, api_id, api_hash)

@client.on(events.NewMessage(incoming=True))
async def handle_message(event):
if event.is_private: # отвечает только в личных сообщениях
response = openai.ChatCompletion.create(
model="gpt-3.5-turbo",
messages=[{"role": "user", "content": event.text}]
)
await event.reply(response['choices'][0]['message']['content'])

client.start()
client.run_until_disconnected()

Использование UserBot-ов нарушает правила Telegram и может привести к бану.

Бесплатные API ChatGPT часто нестабильны.

Для надёжности лучше использовать официальный API OpenAI (но он платный).
